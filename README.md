📊 Government Data Dashboard for Public Spending Analysis

📌 Project Overview

Managing public funds efficiently is crucial for any government. This project is designed to analyze government spending across different sectors using an interactive dashboard. By tracking budget allocations, expenditures, and key financial indicators, it helps policymakers and analysts make data-driven decisions to improve financial transparency and efficiency.

📂 Dataset Details

File: Large_Budget_Expenditure_Extended.xlsx

Key Data Points:

Year & Sector: Identifies the fiscal year and category of government spending.

Budget Metrics: Allocated, spent, and projected budgets, plus variance calculations.

Macroeconomic Indicators: Inflation rate, GDP growth, unemployment rate.

Revenue & Investment: Tax revenue, foreign investments, and innovation funding.

Impact Scores: Environmental impact, public opinion, and education quality index.

Corruption & Success Metrics: Corruption index and project success rate.

Source: Government expenditure reports, economic datasets, and public finance records.

🚀 Key Features

✔️ Interactive Visualizations – Easily explore budget trends and spending patterns.
✔️ Sector-wise Breakdown – See where funds are allocated in areas like Education, Defense, Healthcare, and Infrastructure.
✔️ Historical Comparisons – Analyze how spending has evolved over time.
✔️ Performance Metrics – Evaluate budget efficiency, social impact, and investment returns.
✔️ Predictive Insights – Use machine learning to forecast future budget trends.
✔️ Google Colab Compatibility – Run and visualize all data in Google Colab for ease of access and collaboration.

🛠 Technologies Used

Programming Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn, Plotly, Dash

Visualization Tools: Power BI, Tableau, Google Colab

Machine Learning: Scikit-Learn, XGBoost (for budget forecasting)

Web Framework (if applicable): Flask, Dash
